# 环形测量流程实现说明

将 V5 接入环形图像完整测量流程；当前没有设备标定，用户选择先使用仿真标定验证。

## 设计

灰度预处理 → 环形 ROI → 极坐标展开 → V5 法线重心与 Steger → 亚像素坐标反变换 → 标定重建 → 圆／椭圆拟合 → 内径、圆度及多截面分析。V5 核心、原45张数据及测量结果保留。

`src/ring_measurement/` 按极坐标、标定、几何、流程和轴向分析拆分模块。展开横轴角度、纵轴半径；从图像右侧开始顺时针，默认3600个独立角度样本即0.1°。技术方案同时写有1°/点和3600点，采用更密的后者，不把插值点当作测量点。周期上下文处理接缝，反变换保留精修后的亚像素角度。

标定支持针孔相机内参、五参数畸变和激光平面的三维重建，以及已校正、等比例测量平面的环规比例标定；以JSON提供参数和仿真来源标记。无标定只输出像素指标。缺失点保持无效，覆盖率不足不判为完整测量。保留原始轮廓和拟合离群点标记，真实磨损不能被静默滤掉。圆度使用最小二乘圆基准径向峰谷差，明确区别于最小区域圆度。

多截面使用轴向位置和共同坐标基准，计算锥度、中心线直线度及固定基准轴的中心偏移。程序提供环形仿真和外部PNG/JPEG入口，保存输入、真值、点集、报告及过程总览。计时包含定位、展开、V5、反变换、标定和几何计算，不含采集、生成或文件保存。

## 实施计划

1. 坐标往返、接缝、越界、畸变、光线平面重建、拟合和缺失点先写测试，观察失败。
2. 实现 `polar.py`、`calibration.py`，通过已知几何真值检查。
3. 实现 `geometry.py`、`sweep.py`，检查离群点、椭圆、锥度和共同基准。
4. 实现 `pipeline.py` 接入V5，检查完整圆、偏心展开、空图、接缝断裂与有效点。
5. 保存3600点仿真验证结果，提供外部图像入口，运行全套回归检查和代码审查。
6. 更新README和最终文件校验清单，清除新增临时文件，保留原docs。

## 计量边界

仿真使用已知内参和激光平面；真实±0.01 mm、重复5 μm、圆度测量精度0.005 mm仍需设备标定和环规实测。圆度量值与圆度测量误差分别报告。温漂、探杆变形、编码器和相机同步需要真实输入，不编造硬件数据。

## 实际验证

74项单元与回归检查通过，包含原43项V5检查和31项环形、标定、几何及数据保存检查。独立代码审查发现的缺失侧翼、二维导数支持、真实磨损被拟合剔除、位移重复累加及诊断标记丢失问题均已修正并补充测试。

九类环形输入、五个种子共45张图均完成完整算法测量，每图预热2次、计时5次，共225次，最慢186.7 ms。圆环基准法向RMSE为0.0424–0.0442 px，五种子内径范围0.004432 mm；像素/覆盖率/时间联合通过34/45图。

本模型采用512×512图和0.5 mm/px，强噪声、部分弱光及断裂仍未通过开发门槛；反光和副条纹的毫米内径误差超出±0.01 mm，圆度测量误差均未达到0.005 mm。不能把流程接通和仿真部分指标通过解释为整机满足要求。完整数据与报告位于 `result/v5_ring_measurement/`。

6米三截面仿真的锥度变化测得0.00983 mm，真值0.01000 mm；相对固定基准轴的中心偏移包络直径测得0.20697 mm，真值0.20000 mm。截面姿态用 `pose_reference` 标记是零编码器基准还是已含轴向位移；共用frame_id和固定基准轴，三维点云保存在 `wall_cloud.npz`。

环形后端以独立函数命名空间复用V5代码，替换批量分位数、双线性采样、卷积及等价动态规划实现；原V5模块及其原数据未修改。明确主峰只有在代价上能证明与完整动态规划相同才使用快速路径，歧义场景继续计算完整路径。量化与卷积对比测试、随机路径探针和原算法输出对比均通过。
